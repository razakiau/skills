# no-slop

An agent skill that edits prose so it reads like its writer, or audits it for AI-writing patterns without rewriting.

Merged from [blader/humanizer](https://github.com/blader/humanizer) 3.1.0 and [petergyang/no-ai-slop](https://github.com/petergyang/no-ai-slop), both MIT. The skill is in `skills/no-slop/`: `SKILL.md` (process), `patterns.md` (29 patterns, strongest first), `eval.md` (final check).
